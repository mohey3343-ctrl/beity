# 🏠 بيتي — ميزانية البيت

برنامج ويب صغير (ملف واحد: `index.html`) لإدارة فلوس البيت من الموبايل:

| الشاشة | بتعمل إيه |
|---|---|
| **الرئيسية** | تقدر تصرف كام النهاردة، خطة الشهر (دخل − التزامات − أقساط − تحويش − استوك = المتاح للمصروف اليومي)، تنبيهات (فاتورة قربت، قسط متأخر، صنف هيخلص)، توزيع المصروف، وآخر 6 شهور |
| **اليومية** | كل جنيه اتصرف أو دخل، متجمّع باليوم. زرار **+** بيسجل مصروف في ثانيتين |
| **استوك البيت** | الأصناف ومعدل استهلاكها، **الجرد** (تكتب اللي عندك)، و**أشتري إيه** (الكمية والتكلفة اللي تكفي شهر أو لحد آخر الشهر المالي) |
| **التزامات وديون** | الالتزامات الشهرية (إيجار، كهربا...) وعلامة دفعت/لأ، والديون مع خطة سداد "كرة التلج" وتاريخ الخلاص |
| **الأهداف** | هدف العربية (آخر 2027): المطلوب تحوّشه كل شهر، وتوقّع هتوصل امتى، مع خيار تحويل أقساط الديون اللي بتخلص للهدف |

## معدل الاستهلاك بيتحسب إزاي؟
في الأول بيستخدم الرقم التقديري اللي انت كاتبه للصنف. لما تعمل جردين بينهم أسبوع أو أكتر:

```
الاستهلاك = (الجرد الأول + اللي اتشرى بعده − الجرد الأخير) ÷ عدد الأيام
```

ومن ساعتها بيستخدم استهلاكك الحقيقي، والموجود المتوقع = آخر جرد + المشتريات − الاستهلاك من يومها.

## التشغيل
- فعّل GitHub Pages للريبو ده (Settings ← Pages ← Branch: `main` / root)، وافتح `https://mohey3343-ctrl.github.io/beity/`.
- من الموبايل: Share ← **Add to Home Screen** عشان يفتح زي التطبيق.
- البيانات بتتحفظ على الجهاز. من **الإعدادات** تقدر تنزّل نسخة احتياطية أو تسترجعها.

## المزامنة مع جوجل شيت (اختياري، ومستحسن)
عشان البيانات ما تضيعش لو الموبايل اتمسح، وعشان تفتحها من أكتر من جهاز:
1. اعمل Google Sheet **جديد** (منفصل عن شيت العمارة).
2. Extensions ← Apps Script، والصق `Code.gs`، وغيّر `SECRET`.
3. Deploy ← New deployment ← Web app (Execute as: Me، Who has access: Anyone).
4. حط الرابط وكلمة السر في **الإعدادات ← المزامنة مع جوجل شيت**.

السكريبت بيرفض أي رفع بيصغّر البيانات فجأة، أو بيكتب فوق نسخة أحدث من جهاز تاني، وبيعمل نسخة احتياطية يومية جوه الشيت (آخر 14 يوم).

فيه اختبارات بتشغّل التطبيق في متصفح حقيقي وبتتأكد من الحسابات (الرصيد، الاستوك والعبوات، مواعيد السداد، الديون، الجمعية، المحافظ، الفواتير، الحدود، الكاش فلو...):

```
npx playwright install chromium
npm test
```
